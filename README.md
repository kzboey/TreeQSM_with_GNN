# TreeQSM_with_GNN
Classification of tree species with TreeQSM data structure using 6 GNN models - Graph convolutional networks (GCN), Graph isomorphism network - GIN, graph attention networks (GAT), Graph Sample and Aggregated Embeddings (GraphSAGE) , Attention based graph neural network (AGNN), Auto-regressive moving average convolutional layer (ARMA)
